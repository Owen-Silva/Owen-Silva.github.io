Quartz

My own browser. Claude beside any page, Windows programs and my Android phone all open in it next to ordinary web pages. The first version took six days; it has been Quartz since 26 September.

The five stages

    Why it holds together

    • Decoding runs in the page with WebCodecs, at roughly 1 ms a frame, so the cost is in the link and not in the decoder.
    • The paint happens in the decoder’s own callback. Waiting for the next animation frame instead was what dropped a quarter of them.
    • Stream quality follows a TCP round-trip probe rather than adb’s own timing, because asking adb how long something took costs about 170 ms even on a 7 ms link.

    01 — The product

    What it does, and how it holds

    What it does

    • Claude beside a page: a real Claude Code session in a pane next to the page, on one key, with “Ask Claude about this page” and “Show Claude this page” in the right-click menu. Claude had tabs of its own until 8 October; now it lives only beside a page.
    • App tabs: real Windows programs hosted inside a tab, opened from a dock or by typing in the address bar.
    • Phone workspace: mirrors and fully controls my Android phone. The mouse acts as touch, and the clipboard works both ways.
    • Workspaces: the School workspace opens the right section of my class notes for the question on screen.
    • The address bar searches my own things before the web: open tabs, saved sites, sections of my school notes and project folders, then apps and history. Keywords like “yt” or “gh” search one site directly.
    • Saved sites: a star in the address bar or Ctrl+D, and a Saved row on the new tab.
    • New tab Home: live system readouts, a process list and an apps dock. Every piece can be hidden, put back or dragged anywhere, with snapping and no overlaps.
    • Autocorrect as I type, in every tab and in Quartz itself, through the Windows spellchecker, with a personal dictionary and a per-site off switch.
    • One look with my other apps: Quartz shares its theme, accent colour and glass with Helm and Mantle, and its background lines up with the desktop wallpaper behind the window.
    • It can be the Windows default browser. A link clicked in any other app opens as a tab in the window that is already up.
    • Ad blocking, reader view, split view, a command palette, tab sleep and picture-in-picture.
    • Phone sound plays on the computer, the phone or both, chosen from the phone rail.

    How it’s built

    • Phone video decoded in the page with WebCodecs: about 59 fps at roughly 1 ms per frame. Painting from the decoder callback, instead of waiting for the next animation frame, stopped a quarter of frames from dropping.
    • Quality that adapts to a TCP round-trip probe, because timing adb itself costs about 170 ms even on a 7 ms link.
    • Windows apps hosted through Win32 SetParent via koffi, with no native rebuild. It passed 30 of 30 live checks with Paint.
    • CPU fixes, measured. The animated background went from 27% to 3% of a core, and stats sampling from 4.7% to 0.35%.
    • Memory, measured. A camera service that any page could start never exited; now it quits 5 seconds later. The standard memory test with one camera check went from 745.3 to 712.7 MB private.
    • It runs as Quartz.exe, a copy of Electron stamped with its own name and icon, so Task Manager lists Quartz instead of Electron.
    • The rename kept everything: the first start as Quartz moves the old profile folder in one rename, and refuses to start rather than start empty.
    • About 550 ms cold start. Hidden workspaces go to sleep, which fixed a 1.9 GB GPU process.
    • No silent failures. Every state shows its reason and what to do next.
